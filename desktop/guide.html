需要 Node.js 才能启动

CCConfig 桌面版直接复用你已安装的 Node.js 运行本地服务，不内置运行时。

安装方式

  1. 用 Homebrew：brew install node
  2. 或从官网下载安装包：nodejs.org/download

版本要求 >= 18。装好后请完全退出并重新打开 CCConfig。

如果已经装了 Node，但仍然看到这个页面

从「访达/Dock」启动的应用拿不到终端里的 PATH，nvm / fnm / volta 管理的 Node 常常探测不到。可以手动指定路径：

# 1. 在终端确认 node 位置
which node

# 2. 用环境变量指定后重启应用
CCCONFIG_NODE=$(which node) open -a CCConfig

也可以设置一次全局 launchctl 变量，让 Dock 启动时也生效：

launchctl setenv CCCONFIG_NODE $(which node)

排查

启动日志写在 ~/.ccconfig/logs/sidecar.log，其中会列出所有尝试过的 Node 路径。
