# 多语言（i18n）约定

CCConfig 支持简体中文（`zh-CN`）与英文（`en-US`）。所有面向用户的文案必须走翻译，不允许在 Vue / JS 里硬编码中文（注释、`console.*` 日志除外）。

## 文案目录

单一事实来源在仓库根目录 `shared/i18n/<locale>/`，按域拆 JSON：

```
shared/i18n/zh-CN/
  common.json  nav.json  settings.json  appearance.json  agents.json
  model.json   mcp.json  skill.json    time.json
  claude.json  opencode.json  pi.json  omp.json  reasonix.json
  codex.json   kimi.json  minimax.json qoder.json  zcode.json
  hermes.json  dsh.json  commonApp.json usage.json
  service.json serviceAgent.json native.json
```

- `service.json` / `serviceAgent.json` 给 preload & 桌面 sidecar 用（按 `service.*` / `serviceAgent.*` 组织）；`native.json` 给 Rust 侧用（引导页标题，以及注入 `desktop/tray.html` 托盘弹窗的 `tray` 子树）。

- 每个文件的根节点就是命名空间（`common` / `claude` / `usage` …），Vue 侧通过 `import.meta.glob` 自动合并。
- 新增文案时，**同时**写入 `zh-CN` 与 `en-US` 的同名 key，key 集合必须完全一致。
- 嵌套结构用语义化 key，不要用中文原文当 key。例：`claude.config.nameRequired`、`mcp.fetchToolsFailed`。
- 插值用 `{name}`；英文复数用 `{count} item | {count} items`，中文只写单数形式。

## Vue 组件

```vue
<script setup>
import { useI18n } from 'vue-i18n'
const { t } = useI18n()
</script>

<template>
  <Dialog :header="t('claude.config.editTitle')" :confirm-btn="{ content: t('common.save') }" />
  <Input :placeholder="t('claude.config.namePlaceholder')" />
  <Tooltip :content="t('common.edit')" />
  <Empty :description="t('common.empty')" />
</template>
```

- `header` / `content` / `placeholder` / `description` / `title` 等属性用 `:xxx="t('...')"`（不要写成静态 `content="..."`）。
- `confirm-btn` / `cancel-btn` 对象里的 `content` 也要翻译。
- `Select` / `Radio` / `Checkbox` 的 `label` 翻译，`value` 永远不翻译。
- 模板里不要把 `t` 用作循环变量名（已有代码里的 `.find((t) => ...)` 要改名）。

## 非 setup 代码（composables / utils / 数据表）

```js
import { t } from '../i18n' // 相对路径按文件位置调整
MessagePlugin.success(t('claude.config.saved'))
```

模块级常量里的展示文案改成 `labelKey`，在渲染/计算时 `t(labelKey)`；不要在该模块 import 时求值。

## 动态 / 复数

```js
MessagePlugin.error(t('claude.plugin.addFailed', { message: e.message }))
t('common.imported', { count: ok })
```

英文 JSON：`"imported": "Imported {count} config | Imported {count} configs"`。

## 绝对不要翻译

- DB 文档 ID（`ccconfig_*`）、agent id、env key、provider/model ID、配置名、MCP 名称、文件路径。
- 任何 `value` / `key` / `trueValue` / `id` 字段，以及用于比较、查找、写入配置的字符串。
- 品牌/产品名：Claude Code、OpenCode、Pi Agent、omp、Reasonix、Codex、Kimi Code、MiniMax Code、Qoder、ZCode、Hermes、DSH、MCP、Skill、Plugin、Token、API Key、Base URL、HTTP/STDIO、TRACE。
- 注释与 `console.*` 日志（开发者可见，不是 UI）。
- 第三方市场返回的分类/描述/README（SkillHub、ModelScope、模型列表）。
- 写入其他应用配置文件的生成内容（YAML 头注释、codex 模型目录标记等），它们同时是数据/检测标记。

## 已提供的共享 key（优先复用）

`common.*`：save / cancel / delete / edit / add / confirm / close / copy / copied / copyFailed / search / loading / refresh / empty / unknown / none / default / enabled / disabled / enable / disable / current / all / yes / no / ok / back / reset / upload / download / retry / operationFailed / saveFailed / deleteFailed / loadFailed / fetchFailed / updateFailed / addFailed / copiedToClipboard / notSet / optional / required / name / more / confirmDelete / processing / countItems / contextWindow / maxOutput / reorganized / noBaseUrl / emptyModelList / duplicateEnvKey / globalSettingsSaved / fieldName / fieldValue / addField / custom / tokenUnit / hide / show

`model.*`：模型弹窗；`mcp.*`：MCP 弹窗/卡片/抽屉；`skill.*`：Skill 安装；`time.*`：相对时间；`nav.*`：页签；`settings.*` / `appearance.*` / `agents.*`：设置弹窗。

## 验证

- `npm run build`（构建包含 Vue 编译与 preload esbuild）。
- `npm run i18n:check`（key 对齐、空值、占位符、英文残留 CJK）。
- 手动切换「设置 → 通用 → English」，检查空态、弹窗、toast、占位符、Tooltip。
